API-Schlüssel

Solange kein aktiver Schlüssel existiert, lehnt die API jeden Aufruf mit HTTP 401 ab. Der Schlüssel wird nur einmal beim Erzeugen angezeigt und kann später nicht mehr eingesehen werden – geht er verloren, einen neuen anlegen.
