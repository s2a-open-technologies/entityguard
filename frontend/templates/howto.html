Anleitung

Was ist EntityGuard?

EntityGuard ist eine Datenschutz-Schutzschicht für LLM-gestützte Anwendungen. Bevor Texte an ein Sprachmodell gesendet werden, erkennt und anonymisiert EntityGuard sensible Daten (z. B. Patienten-IDs, Namen, Diagnosen) auf Basis von Microsoft Presidio und einem deutschen spaCy-Sprachmodell, um DSGVO- und HIPAA-Vorgaben einzuhalten. Über dieses Admin-Interface konfigurieren Sie, welche Datentypen erkannt und wie sie ersetzt werden.

Grundbegriffe

Entität

Der Datentyp, der geschützt werden soll (z. B. PATIENT_ID). Jede Entität hat einen Platzhalter (z. B. [PATIENT_ID]), der die erkannten Werte im anonymisierten Text ersetzt.

Erkennungsregel

Verknüpft eine Entität mit den Regeln, nach denen sie im Text gefunden wird. Eine Erkennungsregel besteht aus einem oder mehreren Mustern und optionalen Kontextwörtern.

Muster

Ein regulärer Ausdruck (Regex), der konkrete Textstellen erkennt, z. B. eine Telefonnummer oder ein bestimmtes ID-Format. Jedes Muster hat einen Score (0.0–1.0), der die Erkennungssicherheit angibt.

Kontextwörter

Begriffe, die in der Nähe eines Treffers die Erkennung wahrscheinlicher machen (z. B. "Patient", "Fall", "Akte"). Sie verbessern die Trefferquote, ohne selbst als Muster zu dienen.

Neue Erkennung einrichten

So legen Sie Schritt für Schritt eine neue Erkennung für einen sensiblen Datentyp an:

  1. Entität anlegen unter Entitäten → Entität erstellen. Vergeben Sie einen eindeutigen Namen und einen Platzhalter für die anonymisierte Ausgabe.
  2. Erkennungsregel erstellen unter Erkennungsregeln → Erkennungsregel erstellen und der zuvor angelegten Entität zuweisen.
  3. Muster hinzufügen in der Detailansicht der Erkennungsregel: Regulären Ausdruck und Score eingeben.
  4. Kontextwörter ergänzen (optional), um die Trefferquote in echten Texten zu erhöhen.
  5. Muster testen mit der Muster-Vorschau auf der Detailseite der Erkennungsregel, bevor Sie live gehen.
  6. Erkennungsregel aktivieren (Status "Aktiv"), damit sie bei der Textverarbeitung berücksichtigt wird.

Tipps

  • Der Score gibt an, wie sicher ein Treffer ist: 1.0 bedeutet höchste Konfidenz, niedrigere Werte eignen sich für unscharfe oder mehrdeutige Muster.
  • Reguläre Ausdrücke folgen der Python-re-Syntax. Testen Sie neue Muster immer zuerst mit der Muster-Vorschau.
  • Inaktive Erkennungsregeln bleiben erhalten, werden aber bei der Textverarbeitung ignoriert – nützlich zum Vorbereiten oder vorübergehenden Deaktivieren einzelner Regeln.
